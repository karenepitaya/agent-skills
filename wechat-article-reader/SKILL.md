# 微信公众号文章抓取

微信有反爬机制，直接访问文章 URL 会返回"环境异常"验证页，拿不到正文。本 skill 用真实 Chrome 加持久化浏览器档案绕过检测，把文章转成 agent 可读的 Markdown 文件。

## 使用方法

在工作区根目录运行：

```powershell
uv run --project <本skill目录> <本skill目录>\scripts\wechat_reader.py "<文章URL>"
```

参数：

- `-o <目录>`：输出目录，相对于当前工作目录，默认 `公众号文章/`
- `--headed`：直接用有头浏览器。首次使用或会话失效时用，方便手动过验证

首次运行前先在本 skill 目录执行 `uv sync`（直接 `uv run` 也会自动同步）。

## 工作流程

1. 运行脚本完成抓取：先用无头模式，15 秒内出结果；被风控拦截时自动弹出浏览器窗口，请用户手动完成一次滑块验证。会话保存在 `scripts/_wx_profile/`，之后长期免验证。
2. 脚本输出原始 Markdown：每篇文章一个 `.md`，头部 YAML frontmatter 记录标题、公众号、作者、发布日期、原文链接，图片已下载到 `images/` 并引用本地路径。
3. **agent 清洗**：读取生成的 `.md`，删除非正文内容后原地保存。最终交付物必须是一份干净的 Markdown。

## 清洗要求（agent 执行）

脚本刻意不做内容清洗——公众号模板千差万别，规则式清洗容易失效，而判断"哪段是正文"正是 agent 擅长的。拿到原始 Markdown 后通读一遍，删掉不属于文章本身的内容，常见的有：

- 赞赏组件的残留文字（"赞赏作者""最低赞赏""确定/返回"、数字键盘等）
- 关注、分享、点赞、在看等按钮和引导语
- 二维码、"扫码关注""微信扫一扫"相关段落
- 正文之后的推广区：好文推荐、往期推荐、会议/课程/活动广告、公众号名片等
- IP 属地行（如"广东，2026年10月2日"）等页面元信息

保留：正文全文、有意义的配图引用、原文链接类参考引用、frontmatter。清洗只删不加，不要改写正文表述。

## 注意事项

- 微信图片有防盗链且会过期，脚本已做本地化，这一步不能省。
- 原文随时可能被删除，抓取即存档，不要只存链接。
- 抓取完成后直接 read 生成的 `.md` 文件阅读全文。
- 批量抓取时链接间留 10 秒以上间隔，避免触发风控。
- 依赖 `playwright`、`markdownify`、`requests`，由 uv 管理（见 `pyproject.toml` 和 `uv.lock`）。本机需装有 Chrome。
