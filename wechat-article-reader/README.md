# wechat-article-reader

抓取微信公众号文章为本地 Markdown（正文 + 图片本地化），让微信私域内容对 agent 可读。

## 工作原理

微信对非浏览器环境返回"环境异常"验证页而不是正文。本工具不伪造请求，而是驱动**本机真实 Chrome** + **持久化浏览器档案**（`scripts/_wx_profile/`），让风控看到的与正常用户无异；拿到渲染后的 DOM 再转 Markdown。

## 环境要求

- 桌面操作系统（Windows / macOS / Linux）
- 本机已安装 **Chrome**（脚本以 `channel="chrome"` 驱动系统浏览器）
- [uv](https://docs.astral.sh/uv/)（依赖管理）

## 快速开始

```powershell
uv sync                                          # 首次：按 uv.lock 还原环境
uv run scripts/wechat_reader.py "<文章URL>"      # 抓取
```

输出（相对当前工作目录）：

```
公众号文章/<发布日期>-<标题>.md     ← 正文 + YAML frontmatter（标题/公众号/作者/日期/原文链接）
公众号文章/images/                  ← 本地化的配图
```

## 常见问题

能解决的全都给了方案；解决不了的在 ⚠️ 里明说。

| 问题 | 应对 |
|------|------|
| 首次运行 / 换新机器后抓取失败 | 微信对新环境必拦。加 `--headed` 跑一次，在弹出的窗口里手动完成验证；信任会话写入 `_wx_profile/`，之后该机器长期免验证 |
| 用了一段时间后又开始被拦 | 会话过期，同上：`--headed` 重过一次验证即可 |
| 公众号名 / 作者字段为空 | 微信新版文章模板异步渲染，脚本已做等待 + 多选择器兜底（新旧模板均兼容）；个别页面仍为空属于页面本身未提供该信息 |
| 图片过几天打不开了 | **不会发生**：抓取时图片已全部下载到本地。微信图片有防盗链且 URL 会过期，切勿跳过本地化直接存远程图链 |
| 原文被作者删除 | 不影响：本地 Markdown 是完整快照，`source` 字段仅作溯源留档 |
| 批量抓取多篇文章 | 链接间间隔 ≥10 秒，避免触发频率风控 |
| ⚠️ 服务器（数据中心 IP）上运行 | **暂未适配**。机房 IP 被拦概率高，且无人滑验证。建议：把本工具部署在住宅网络的常开机器上包成服务，服务器上的 agent 远程调用 |
| ⚠️ 无 Chrome 的纯 Linux 服务器 | **暂不支持**。脚本依赖系统 Chrome 的指纹，换成 Playwright 自带 Chromium 会显著提高被拦概率，需自行改造并重新评估 |
